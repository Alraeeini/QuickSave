QuickSave هو تطبيق حديث لنظام Android لتحميل الوسائط، صُمم لجعل تحميل الفيديوهات والصوتيات المدعومة سريعًا وسهلًا ومريحًا.

## ✨ المميزات

- ⚡ **المشاركة السريعة** — مشاركة الرابط مباشرةً إلى QuickSave.
- 🎬 **الفيديو والصوت** — فيديو مع صوت أو صوت فقط، مع جودة تصل إلى 1080p.
- 📋 **قوائم تشغيل YouTube** — اختيار فيديوهات فردية أو متعددة وتحميلها دفعة واحدة.
- 📚 **مكتبة قوائم التشغيل** — حفظ القوائم محليًا ومتابعة التحميل لاحقًا.
- ⏬ **قائمة انتظار التحميل** — إدارة عدة تحميلات وتحديد عدد التحميلات المتزامنة.
- ⏸️ **إيقاف واستئناف** — إيقاف واستكمال التحميلات المدعومة.
- ⏯️ **إيقاف/استئناف الكل** — التحكم في قائمة الانتظار بالكامل بضغطة واحدة.
- ✂️ **القص / Clip** — تحميل جزء محدد من المحتوى.
- 🎵 **تقسيم الفصول** — تقسيم المحتوى المدعوم إلى ملفات منفصلة حسب الفصول.
- 📁 **مجلد مخصص** — اختيار مكان حفظ الملفات.
- 📚 **سجل التحميلات** — عرض وفتح ومشاركة وحذف وإعادة محاولة التحميلات.
- 🔔 **التحميل في الخلفية** — استمرار التحميل أثناء استخدام تطبيقات أخرى.
- 📊 **التقدم المباشر** — السرعة والنسبة والحجم والحالة.
- 🔄 **إعادة المحاولة التلقائية** — استعادة التحميلات الفاشلة.
- 🔐 **جلسات تسجيل الدخول الاختيارية** — متصفح مدمج وملفات كوكيز للمنصات المدعومة.
- 🌍 **متعدد اللغات** — English وItaliano والعربية مع دعم RTL.
- 💾 **النسخ الاحتياطي والاستعادة** — حفظ بيانات التطبيق واستعادتها عبر JSON.

## 🧠 الأداء

يستخدم QuickSave التجهيز المسبق والتخزين المؤقت المؤقت لتحضير معلومات الوسائط في الخلفية وتقليل عمليات التحليل المتكررة.

## 🎯 طرق الاستخدام

**يدوي:** افتح QuickSave → أدخل الرابط → اختر الخيارات → حمّل

**المشاركة السريعة:** شارك الرابط → Quick Share → اختر الخيارات → حمّل

**تلقائي:** شارك الرابط → يبدأ QuickSave التحميل في الخلفية
